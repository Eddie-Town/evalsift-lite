# Product description (draft)

EvalSift is a set of agent skills plus a zero-dependency Python harness that takes you from raw
LLM traces to a calibrated judge: label failures, build a failure taxonomy, check your judge
against human labels, and gate regressions in CI. It ships with a worked case study: 100
hand-labeled traces from a tool-using support agent, including 12 real failures and how each was caught.

Note: this is for the checkout page. HN's moderators ask that Show HN text not be LLM-written,
so write the Show HN post yourself and use this only as notes.

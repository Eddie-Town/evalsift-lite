# q087: "free over $75" is not "free at $75"
**Customer asked:** Is shipping free on exactly $75?

**What went wrong:** The policy says standard shipping is free *over* $75, otherwise $6.95.
The agent said a $75.00 order ships free.

**Why it matters:** The agent quoted the right policy and still got it wrong. An LLM judge
reading quickly will likely pass this answer. Boundary cases like this need a
deterministic check (a code grader with the exact threshold).

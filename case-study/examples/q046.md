# q046: a correct answer to the wrong question
**Customer asked:** If I return my backpack from order 1004, how long until I get my money?

**What went wrong:** The order was delivered more than 30 days earlier, so it could no longer
be returned. The agent didn't make clear that the return window had expired.

**Why it matters:** The customer asked about refund timing, but the real answer was
"you can't return this." Agents that answer the literal question can skip the
precondition that makes the question moot. Good test cases check the precondition, not just the wording.
